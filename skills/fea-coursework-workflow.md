# 有限元仿真课设工作流

> 优先级：高

## 概述

把"接到一个有限元仿真类课设/专题任务"到"形成小论文"的完整过程固化为六阶段标准流程（A–F），
每一步都有目标、输入、输出和完成定义。流程层与求解器无关，换软件只改工具操作层；针对显式冲击/
波动类问题（落锤、碰撞、爆炸），内置能量守恒、沙漏、网格收敛等质量门与判据。

本技能由原"仿真类课设工作流包（A–F 六阶段）"与"仿真工作流程模板（显式冲击五阶段）"两个高度
相关的记录合并而成，显式冲击作为其专用分支保留。

## 适用场景

- 结构、冲击、流固耦合、渗流、传热等需要建模、算例、参数扫描、成文的课设或小论文。
- 显式动力学瞬态问题：落锤、碰撞、爆炸、波动传播。
- 求解器不限（LS-DYNA、Abaqus、ANSYS、OpenFOAM、COMSOL），仅卡片名不同。

## 操作步骤

### 阶段 0 · 环境准备

1. 定位求解器可执行文件与许可证，跑一个"要素齐全但极小的冒烟算例"验证许可实际能 checkout
   （端口在线不等于模块可用）。
2. 确认 Python 科学栈（numpy / pandas / matplotlib / scipy）可用。
3. 磁盘预留 ≥50 GB（显式冲击 + 参数扫描结果大），内存 ≥16 GB。
4. 工作目录用 ASCII 路径，避免中文/空格导致求解器或 GUI 找不到文件。

### 阶段 A · 任务解析

把任务书逐句拆为硬性要求、软性/选做要求、交付要求三类；找出隐含的物理问题（静力/动力、线性/
非线性、单场/耦合）；确定软件、单位制、任务边界（2D/3D、精度）。产出任务卡与约束清单，并写出
"一句话问题定义"。

### 阶段 B · 方案与参数

画几何简图并标注尺寸；建立材料参数表（每行写参数值 + 来源）；确定本构（先线性后非线性）；列
工况矩阵（变量、范围、要回答的问题）；把无法从文献得到的参数标记为"假设"集中记录。参数至少
覆盖：几何、材料、载荷、边界、接触。

### 阶段 C · 建模与网格

几何 → 材料 → 网格（先粗后细，冲击区/缺陷区加密）→ 边界与初始条件 → 接触 → 输出设置。网格
要点：冲击区单元尺寸 ≈ 接触尺度/5~10；缺陷区 ≥10 个单元解析；相邻尺寸比全程 ≤3，禁止台阶式
突变；显式问题注意最小单元对时间步的控制。所有操作存成脚本，保证可复现。

### 阶段 D · 基准验证

先跑最简单工况（无缺陷、单落高、单载荷），再依次做：网格无关性（至少加密一档，关键量相邻两档
差异 <5%）、能量守恒（总能量漂移 <1%）、沙漏校核（沙漏能/内能 <5–10%）、边界吸收校核，并与
解析解/经验值/文献结果比对误差。验证通过后把基准设置冻结为可复现基线。

### 阶段 E · 参数研究

只改变计划中的变量，其余设置与基准保持逐字节一致；每个算例按命名规范命名并记日志；提取统一
响应量（位移、应力、塑性应变、能量等）；用表格 + 曲线展示规律；对阈值/最优值给出明确物理判据；
异常算例单独记录，不悄悄删除。

### 阶段 F · 后处理与成文

按论文结构模板搭章节骨架；先做图表后写正文；摘要最后写；引言按任务书要求只写背景；结论逐条
回应任务目标；检查单位、有效数字、图表编号与正文引用；参考文献真实可查。

每进入下一阶段前对照 `templates/quality-gates.md` 勾选完成定义，未通过就回到当前阶段补齐。

## 关键参数

完整参数模板见 `templates/fea-param-table.csv`，核心项：

| 类别 | 参数 | 取值要点 |
|---|---|---|
| 几何 | 范围、层厚、锤半径 | 覆盖关心区域并延迟边界反射 |
| 材料 | E、ν、ρ、本构 | 每项注明来源或假设；剑桥/盖帽参数按土工试验标定 |
| 载荷 | 落高 h、初速度 | 接触初速度 v0=√(2gh)，等价于自由落体 |
| 接触 | 摩擦系数 μ | 必须注明来源 |
| 缺陷 | 尺寸、埋深、弱化倍数 | 轴对称下横向偏移 >0 表示环状而非球 |
| 网格 | 冲击区/缺陷区/远场尺寸 | 冲击区≈接触尺度/5~10，缺陷区≈尺寸/10~12，相邻比 ≤3 |
| 验证 | 能量漂移、沙漏/内能 | <1%、<5–10%（完全积分=0） |

## 常见失败情况

详见 `troubleshooting.md` 的"仿真求解"分节。高频坑包括：

- 跳过基准验证直接做参数扫描，错误结果被放大复制。
- 只在 GUI 里点不存脚本，换设备无法复现。
- 接触主从面搞反，导致穿透或异常应力。
- 单点积分单元在欠解析冲击区沙漏失稳（能量暴涨），改用完全积分（NIP=4）。
- 无反射边界节点排序错误，或侧边界跨分层导致数值失稳。
- 参数扫描时顺手改了其他设置，结果无法对比。
