# 质量门检查清单（勾选式）

每进入下一阶段前逐项对照，未通过就回到当前阶段补齐。

## 阶段 1 · 环境

- [ ] 求解器可执行文件可定位
- [ ] 许可证实际 checkout 成功（冒烟算例验证，非仅端口监听）
- [ ] Python：numpy/pandas/matplotlib/scipy 可导入
- [ ] 磁盘空闲 ≥50 GB、内存 ≥16 GB
- [ ] 冒烟算例正常终止（日志出现 normal termination）

## 阶段 2 · 模型

- [ ] 单位制统一且写死（m-kg-s-N-Pa）
- [ ] 每个简化都有书面理由（对称性/刚体/初速度）
- [ ] 网格无零面积单元、相邻尺寸比 ≤3
- [ ] 冲击区尺寸 ≈ 接触尺度/5~10；缺陷区 ≥10 单元
- [ ] 边界：对称轴 + 无反射 + 自由面，节点顺序正确
- [ ] 输出：测点时程、监测区应力/塑性、能量文件、params.json

## 阶段 3 · 求解验证

- [ ] 所有基准算例 normal termination
- [ ] 总能量漂移 <1%
- [ ] 沙漏能/内能 <5–10%（完全积分=0）
- [ ] 网格收敛：关键量相邻两档 <5%
- [ ] （可选）无吸收边界对照显示反射延迟

## 阶段 4 · 分析

- [ ] 每个数字可追溯（算例目录 + 脚本）
- [ ] 缺陷信号随尺寸单调；埋深-到时线性
- [ ] 信号低于精度时如实报告"不可检"
- [ ] 参数限值有判据线 + 交点标注

## 阶段 5 · 论文

- [ ] 图、表齐且编号一致、正文均被引用
- [ ] 每个参数值有来源（文献/规范/老师给定）
- [ ] 结论有判据；局限与展望完整
- [ ] 参考文献经检索核对，无照抄
